# 🛒 Amazon Sales Dashboard

## 📌 Project Name
**Amazon Sales Dashboard**

---

## 📖 Short Description / Purpose

The **Amazon Sales Dashboard** is an interactive Power BI dashboard designed to analyze Amazon product sales, customer reviews, units sold, and regional sales performance.

This dashboard helps businesses and analysts monitor:
- Product-wise sales performance
- State-wise and city-wise sales
- Sales trends over time
- Product reviews and returns
- Product category insights
- Unit sales analysis

The dashboard provides clear and interactive business insights for improving sales strategies and product performance analysis.

---

## 🛠️ Tech Stack

The following technologies and tools were used in this project:

- **Power BI** → Dashboard development and visualization
- **Microsoft Excel / CSV** → Dataset handling
- **Power Query** → Data transformation and cleaning
- **DAX (Data Analysis Expressions)** → KPI calculations and measures
- **ChatGPT (AI Tool)** → Project guidance and documentation support

---

## 📂 Data Source

The dataset used for this project is based on Amazon sales-related data for educational and analytical purposes.

The dataset contains:
- Product Name
- Product Category
- Sales Amount
- Sales Units
- Review Count
- Return Units
- State
- City
- Order Status
- Date Information

---

## ✨ Features / Highlights

### 📌 Business Problem

E-commerce businesses generate massive amounts of sales data daily.  
Tracking product performance, regional sales trends, customer reviews, and return behavior manually becomes difficult and time-consuming.

This dashboard solves the problem by providing a centralized and interactive sales analytics solution.

---

### 🎯 Goal of the Dashboard

The dashboard aims to:
- Analyze product sales performance
- Monitor sales by state and city
- Track monthly sales trends
- Identify high-performing products
- Compare product reviews and return counts
- Improve business decision-making using visual insights

---
